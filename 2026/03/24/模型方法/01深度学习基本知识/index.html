感知机分类规则

$y = \text{sign}(w \cdot x + b)$ 输出1和0

  • $b$是偏置

  • $w$是权重

用单层感知机可以实现与门、与非门、或门，但是实现不了异或门，但是用双层感知机就可以实现异或门。用多层感知机可以实现非线性的表示。

激活函数

$y =h(w \cdot x + b)$ $h(a)$就是激活函数

$\text{sign}$也是激活函数的一种，在感知机中使用

在神经网络中常见的激活函数有：

  1. Sigmoid函数：输出范围在 $(0,1)$，常用于二分类输出层，但容易出现梯度消失问题。
    $\sigma(x) = \frac{1}{1 + e^{-x}}$

  2. Tanh函数：输出范围在 $(-1,1)$，相比 Sigmoid 更居中，收敛速度通常更快。
    $\tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}$

  3. ReLU函数：当前最常用的激活函数，计算简单，缓解梯度消失，但可能出现“神经元死亡”。
    $f(x) = \max(0, x)$

  4. Leaky ReLU：对 ReLU 的改进，在负区间保留小斜率，缓解神经元死亡问题。
    $f(x)=
    \begin{cases}
    x, & x > 0 \
    \alpha x, & x \leq 0
    \end{cases}$

  5. ELU函数：在负区间具有平滑曲线，有助于提高学习速度和稳定性。
    $f(x)=
    \begin{cases}
    x, & x > 0 \
    \alpha (e^x - 1), & x \leq 0
    \end{cases}$

  6. Softmax函数：将输出转换为概率分布，常用于多分类问题的输出层。
    $\text{softmax}(x_i) = \frac{e^{x_i}}{\sum_{j=1}^{n} e^{x_j}}$

  7. Step函数：最早用于感知机的激活函数，不连续且不可导。
    $f(x)=
    \begin{cases}
    1, & x > 0 \
    0, & x \leq 0
    \end{cases}$

  8. Swish函数：由 Google 提出，平滑且在一些深度模型中表现优于 ReLU。
    $f(x) = x \cdot \sigma(x)$

  9. GELU函数：在Transformer中广泛使用，结合概率思想，效果较好。
    $\text{GELU}(x) = x \cdot \Phi(x)$

激活函数必须要使用非线性函数，因为用多层线性函数可以等效为一个线性函数，为了发挥叠加层的优势，所以要用非线性函数。

常见误差函数

均方误差（MSE）

$L = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2$
用于回归问题，衡量预测值与真实值的平方差，对异常值敏感。

平均绝对误差（MAE）

$L = \frac{1}{n} \sum_{i=1}^{n} |y_i - \hat{y}_i|$
用于回归问题，对异常值不敏感，但梯度不平滑。

均方根误差（RMSE）

$L = \sqrt{\frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2}$
MSE 的平方根，单位与原数据一致，更直观。

交叉熵损失（Binary Cross Entropy）

$L = - \frac{1}{n} \sum_{i=1}^{n} \left[ y_i \log(\hat{y}_i) + (1 - y_i) \log(1 - \hat{y}_i) \right]$
用于二分类问题，衡量概率分布之间的差异。

多分类交叉熵（Categorical Cross Entropy）

$L = - \sum_{i=1}^{n} \sum_{j=1}^{C} y_{ij} \log(\hat{y}_{ij})$
用于多分类任务，通常与 Softmax 搭配使用。

Hinge Loss（SVM）

$L = \max(0, 1 - y \cdot \hat{y})$
用于支持向量机，强调分类间隔（margin）。

对数损失（Log Loss）

$L = - \sum y \log(\hat{y})$
本质就是交叉熵的一种形式，常用于概率模型。

KL 散度（Kullback-Leibler Divergence）

$D_{KL}(P | Q) = \sum P(x) \log \frac{P(x)}{Q(x)}$
衡量两个概率分布之间的差异，常用于生成模型和变分推断。

Huber Loss

$L = \begin{cases} \frac{1}{2}(y - \hat{y})^2, & |y - \hat{y}| \leq \delta \ \delta(|y - \hat{y}| - \frac{1}{2}\delta), & \text{otherwise} \end{cases}$
结合 MSE 和 MAE 的优点，对异常值更鲁棒。

Log-Cosh Loss

$L = \sum \log(\cosh(\hat{y} - y))$
类似 MSE，但对异常值更平滑和稳定。

梯度下降法（求最小值）（梯度上升法同理）

梯度：

$\nabla f(x_1, x_2, \dots, x_n) = \left( \frac{\partial f}{\partial x_1}, \frac{\partial f}{\partial x_2}, \dots, \frac{\partial f}{\partial x_n} \right)$

梯度下降核心公式

$\theta \leftarrow \theta - \eta \nabla J(\theta)$

$\eta$就是学习率

神经网络的一些参数叫作超参数（学习率等）

误差反向传播（比起数值微分更优）

其过程是先通过前向传播计算模型输出与真实标签之间的误差（损失函数），随后利用微积分的链式法则，将该误差从输出层逐层向输入层反向传递，计算出每个神经元权重对误差的影响（即梯度），最后根据梯度更新权重以最小化误差，从而使模型逐渐学习到数据中的模式。

数值微分法一般用于检验反向传播法的实现是否正确

SGD 随机梯度下降法

随机梯度下降法（Stochastic Gradient Descent, SGD）是驱动神经网络不断学习的核心优化引擎，它的本质是在复杂的误差“山谷”中摸索出一条通往谷底（误差最小化）的路径。为了在计算速度与方向准确性之间取得完美平衡，现代工程中主要使用的是小批量（Mini-batch）SGD：它在每次迭代时，会随机抽取一小批训练数据来计算平均误差和梯度（即寻找当前最陡峭的下降方向），随后引导模型参数按照设定的学习率（下山的步长）向梯度的反方向迈出一步，从而通过这种带有轻微随机性、既高效又抗干扰的方式，一步步纠正网络错误并逼近最优解。

局限性：

尽管小批量随机梯度下降（Mini-batch SGD）是深度学习的基础引擎，但它在面对复杂的高维空间时存在明显的**“近视”缺陷**：它容易在狭长的“峡谷”地形中剧烈震荡从而拖慢真正的下山速度，极易在梯度接近于零的鞍点或平坦地带陷入停滞，对所有参数采用**“一视同仁”的死板学习率**导致难以高效处理稀疏特征，且极度依赖人工“炼丹”来调节超参数。正是为了克服这些由于缺乏记忆和变通而造成的短板，科学家们才在此基础上引入了物理“惯性”和“自适应”机制，演化出了 Momentum 和 Adam 等更智能的现代优化器，以此帮助模型更快速、稳定地跨越复杂地形，直达误差的谷底。

Momentum方法

Momentum（动量法） 的灵感直接来源于物理学。
如果把纯 SGD 比作一个“走一步看一步的盲人”，走到平地就停下；那么 Momentum 就是**“一颗沉重的铁球”**。

当这颗铁球在误差山谷中滚下时：

  • 它不仅受到当前坡度（梯度）的推力，还保留着之前的行驶速度（惯性）。
  • 在峡谷中来回撞击时，向左和向右的力量会相互抵消，而向前的力量会不断累加。
  • 遇到平坦的鞍点时，它能凭借积攒的庞大惯性直接冲过去，直到遇到真正向上的大陡坡才会被逼停。

数学公式与推演

为了实现“惯性”，Momentum 引入了一个全新的状态变量：速度 $v$（Velocity）。

其参数更新的数学公式如下：

$$v \leftarrow \alpha v - \eta \frac{\partial L}{\partial W}$$

$$W \leftarrow W + v$$

公式参数解析：

  • $W$：当前需要更新的权重参数（Weight）。
  • $\frac{\partial L}{\partial W}$：当前的误差梯度（即现在的坡度）。
  • $\eta$：学习率（Learning Rate），决定了当前梯度推力的大小。
  • $v$：物体的速度。它记录了之前所有历史梯度的累加效果。
  • $\alpha$：动量系数（Momentum factor），通常设置为 0.9。它相当于物理世界中的地面摩擦力或空气阻力。乘以 0.9 意味着之前的速度会随着时间慢慢衰减，确保铁球最终能稳稳停在谷底，而不是永远来回滚动。

局限性：

尽管解决了“方向”问题，Momentum 依然对所有千差万别的参数使用同一个固定的学习率 $η$。对于出现频率极低的罕见特征，它无法自动调大步伐；对于极其频繁的特征，它也无法自动精细化步长。

AdaGrad（自适应梯度）方法

在之前的 SGD 和 Momentum 中，无论神经网络中的参数负责什么任务，它们在更新时都乘以同一个全局固定的学习率 $\eta$。这在面对稀疏数据（比如自然语言处理中的词频）时，会暴露一个巨大的硬伤：

  • 常见特征（更新频繁）：比如文本中的标点符号或助词，每次训练都能遇到。如果学习率一直很高，它的权重就会在最优解附近来回震荡，无法精细收敛。
  • 罕见特征（更新偶尔）：比如某个生僻字，可能几百次训练才出现一次。好不容易抓到一次更新机会，如果学习率不够大，它只挪动了极其微小的一步，根本学不到有用的信息。

AdaGrad 的解决思路：我们要为成千上万个参数量身定制**“专属学习率”**。
为了实现这种自适应，AdaGrad 引入了一个新的状态变量：梯度平方和 $h$。

累加历史梯度的平方
$$h \leftarrow h + \left( \frac{\partial L}{\partial W} \right)^2$$

  • 这里的平方是逐元素相乘。
  • 物理意义：当前梯度 $\frac{\partial L}{\partial W}$ 无论是正还是负，平方后都是正数。所以 $h$ 只会随着时间推移不断变大。它记录了该参数历史累计的“震荡剧烈程度”。

调整专属学习率并更新权重
$$W \leftarrow W - \frac{\eta}{\sqrt{h} + \epsilon} \frac{\partial L}{\partial W}$$

$\eta$：你一开始设定的全局初始学习率。

  • $\frac{1}{\sqrt{h}}$： 把累加的记录 $h$ 开根号，放在分母上。
    • 如果这个参数过去更新得很猛（$h$ 很大），分母变大，实际学习率 $\frac{\eta}{\sqrt{h}}$ 就会变得非常小（自动刹车）。
    • 如果参数一直没怎么更新（$h$ 很小），分母极小，实际学习率保持较大（自动加速）。
  • $\epsilon$：一个极其微小的常数（如 $10^{-7}$），纯粹的工程补丁，防止遇到 $h=0$ 时发生“除以0”的系统崩溃错误。

局限性：

观察公式：因为平方数永远为正，h只能无脑单调递增，永远不会变小。

随着训练的推进，到了中后期，分母会变得无限大，导致实际学习率趋近于 0。这时候，模型就像是被彻底“冻结”了一样，提前停止了学习。

Adam（自适应矩估计）方法

双重记忆与偏差修正

Adam 为每个参数准备了两个专属笔记本：

  • $m$（一阶矩，First Moment）：记录梯度的动量（方向）。
  • $v$（二阶矩，Second Moment）：记录梯度平方的指数衰减移动平均（自适应步长）。

更新双重记忆
$$m \leftarrow \beta_1 m + (1 - \beta_1) \frac{\partial L}{\partial W}$$
$$v \leftarrow \beta_2 v + (1 - \beta_2) \left( \frac{\partial L}{\partial W} \right)^2$$

  • $\beta_1$：动量系数，通常默认设为 0.9。
  • $\beta_2$：自适应步长衰减系数，通常默认设为 0.999。

偏差修正

Adam 引入了时间步 $t$（当前是第几次迭代）来进行放大修正：

$$\hat{m} = \frac{m}{1 - \beta_1^t}$$

$$\hat{v} = \frac{v}{1 - \beta_2^t}$$

最终的参数更新

$W \leftarrow W - \frac{\eta}{\sqrt{\hat{v}} + \epsilon} \hat{m}$

  • 大一统的公式。分子 $\hat{m}$ 提供了平滑的惯性方向，分母 $\sqrt{\hat{v}}$ 提供了定制化的自适应学习率。

梯度消失

Sigmoid 函数的导数，它的最大值只有 0.25（在 x=0 的时候取得）。 这意味着，误差信号每反向穿过一个 Sigmoid 层，最少最少也会被强行缩小 4 倍（乘以 0.25）。

Sigmoid 函数在输出值接近 0 或 1 的两端极端区域时，其数学导数 y(1−y)会衰减至近乎为 0，这在几何上表现为 S 型曲线两端极其平坦的“饱和死区”；由于反向传播的核心是链式法则的乘法，下游传来的误差信号一旦乘以这个趋近于 0 的局部导数，就会被瞬间“清零抹杀”，导致网络前方的参数根本接收不到更

指令，从而仅过一层就将梯度彻底“掐死”。

表现力受限

当神经网络的权重初始化过小时，各层神经元的接收信号会极度微弱并趋近于0，导致经过激活函数后的输出值高度集中在一个固定点（如Sigmoid的0.5），这种现象被称为“表现力受限”。这会引发一场可怕的“对称性噩梦”：同一层的所有神经元在前向传播时输出完全相同的同质化信号，失去了各自

取不同特征的分工协作能力；同时在反向传播时，它们也会因此分到一模一样的误差梯度，导致所有参数永远在同步更新、无法产生差异。最终，原本拥有成千上万参数的宽大网络，其实际的非线性表达和特征提取能力瞬间退化到如同只有一个神经元，彻底丧失了学习复杂数据规律的能力。

Xavier初始值

在早期的深度学习中，如果权重（Weight）的初始值设置不当，网络在仅仅经历几次前向传播后就会面临两种灾难：

初始值太大：数据被无限放大，挤入激活函数的饱和区，导致梯度消失（网络死机）。

初始值太小：数据不断衰减，所有神经元输出高度同质化的微弱信号，导致表现力受限（网络变傻）。

数学表达即为：

$$\text{Var}(Y) = \text{Var}(X)$$

只有保持方差（分散程度）不变，信号才不会在深层网络中爆炸或干涸。

假设我们有一个极其基础的线性运算：

$$Y = w_1 x_1 + w_2 x_2 + \dots + w_n x_n$$（

其中 $n$ 是上一层的神经元数量，即输入特征的数量，通常记作 $n_{in}$）。

假设输入 $X$ 和权重 $W$ 都是相互独立的，且它们的平均值均为 0。根据概率论的方差公式，我们可以推导出输出 $Y$ 的方差为：$$\

text{Var}(Y) = n \cdot \text{Var}(w_i) \cdot \text{Var}(x_i)$$

为了让输出的方差等于输入的方差，即 $\text{Var}(Y) = \text{Var}(x_i)$，我们必须让中间的乘数等于 1：
$$n \cdot \text{Var}(w_i) = 1$$

$$\text{Var}(w_i) = \frac{1}{n}$$

因为我们在代码里生成正态分布时传入的是标准差（Standard Deviation, $\sigma$），而标准差是方差的平方根，所以最终公式为：
$$\sigma = \frac{1}{\sqrt{n}}$$

局限性：

致命短板（当 Xavier 遇到 ReLU）

因为 ReLU 会极其残忍地把所有负数全部砍成 0，这意味着信号每穿过一层 ReLU，方差就会直接**腰斩（减半）**传着传着，方差还是缩成了 0

He初始值

Sigmoid 实在太容易饱和，大家开始使用 ReLU，为解决 ReLU与Xavier的问题，提出He初始值

回顾一下 Xavier 初始化的方差目标：

$$n \cdot \text{Var}(w_i) = 1$$

解得 Xavier 的方差为 $\frac{1}{n}$，标准差为 $\frac{1}{\sqrt{n}}$。

而在 He 初始化中，因为 ReLU 砍掉了一半的信号，为了维持输出的方差等于输入的方差，等式变成了：

$$\frac{1}{2} \cdot n \cdot \text{Var}(w_i) = 1$$

$$n \cdot \text{Var}(w_i) = 2$$

$$\text{Var}(w_i) = \frac{2}{n}$$

因为生成正态分布时需要传入标准差（$\sigma$），对方差开根号后，我们得到了 He 初始化的终极公式：

$$\sigma = \sqrt{\frac{2}{n}}$$

就这多出来的一个 $\sqrt{2}$，犹如神来之笔，完美对消了 ReLU 带来的方差衰减，让上百层的极深神经网络（如 ResNet）的训练成为了可能。

Batch Normalization 批归一化，BN层

拿当前这一个小批量（Mini-batch，比如 100 张图片）的数据，算出它们的均值 $\mu_B$ 和方差 $\sigma_B^2$，然后用这两个值把数据强行标准化。

但是，当模型训练好，拿去给用户实际使用（推理/预测 Inference）时，灾难来了：

  • 真实场景下，用户通常是一张一张地传图片（Batch Size = 1）。
  • 1 张图片的均值就是它自己，方差是 0
  • 如果这时候你再去套用 BN 的公式除以标准差，分母直接变成 0（或者极小的 $\epsilon$），算出来的结果会彻底爆炸，模型直接吐出一堆乱码。
  • 退一步说，哪怕用户传了 3 张图片，你算这 3 张图片的均值和方差，也完全不能代表整个世界的数据分布。

因此，BN 层必须被设计在训练时和预测时，底层运行的是两套完全不同的逻辑。

训练阶段 (Training)：

在训练时，BN 层不仅要负责把当前 Batch 的数据标准化，它还要暗中执行一个极其重要的**“记账”**任务。

  1. 计算当前 Batch：算出这 100 张图的均值 $\mu_B$ 和方差 $\sigma_B^2$，并用它们对当前数据进行归一化。

  2. 更新学习参数：通过反向传播，让网络自己学习缩放因子 $\gamma$ 和平移因子 $\beta$。

  3. 维护全局滑动平均 (Moving Average)：

    BN 层会在后台偷偷准备两个全局变量（全局均值 $\mu_{moving}$ 和全局方差 $\sigma^2_{moving}$）。每次进来一个 Batch，它就会按一定比例把当前 Batch 的统计值融合进去：
    $$\mu_{moving} \leftarrow \alpha \mu_{moving} + (1 - \alpha) \mu_B$$

    $$\sigma^2_{moving} \leftarrow \alpha \sigma^2_{moving} + (1 - \alpha) \sigma_B^2$$

    $\alpha$ 通常是一个接近 1 的动量值（如 0.99）。

    意义：经过成千上万次迭代，这两个全局变量就精确记录了“整个训练集（所有图片）的真实均值和真实方差”

预测阶段 (Inference)：

当模型部署上线，进入预测阶段时，BN 层的逻辑会发生 180 度大转弯：

  1. 冻结参数：网络停止学习，$\gamma$ 和 $\beta$ 固定为你训练出来的最终形态。

  2. 抛弃当前 Batch 统计：不管用户传进来 1 张图片还是 10 张图片，BN 层绝对不去算它们的均值和方差。

  3. 调取全局档案：BN 层直接翻开在训练时记下的“全局档案”，拿出 $\mu_{moving}$ 和 $\sigma^2_{moving}$。

  4. 执行归一化：

    $$\hat{x}{test} = \frac{x{test} - \mu_{moving}}{\sqrt{\sigma^2_{moving} + \epsilon}}$$

    然后套上固定的 $\gamma$ 和 $\beta$：$$y_{test} = \gamma \hat{x}_{test} + \beta$$

正则化（抑制过拟合）

发生过拟合的原因，主要有以下两个。

  • 模型拥有大量参数、表现力强。

  • 训练数据少

==权重衰减：==

L2 正则化是在原始的损失函数（$Loss_{data}$）后面，加上了所有权重的平方和：

$$Loss_{total} = Loss_{data} + \frac{1}{2} \lambda W^2$$

对权重 $W$ 求偏导（算梯度）

根据加法求导法则：

$$\frac{\partial Loss_{total}}{\partial W} = \frac{\partial Loss_{data}}{\partial W} + \lambda W$$

代入 SGD 的参数更新公式

$W_{new} = W_{old} - \eta \cdot \text{梯度}$ （其中 $\eta$ 是学习率）。

把上面的新梯度代入进去：

$$W_{new} = W_{old} - \eta \left( \frac{\partial Loss_{data}}{\partial W} + \lambda W_{old} \right)$$

$$W_{new} = W_{old}(1 - \eta \lambda) - \eta \frac{\partial Loss_{data}}{\partial W}$$

仔细看 $W_{old}(1 - \eta \lambda)$ 这一项。

因为学习率 $\eta$ 和惩罚系数 $\lambda$ 都是极小的正数（比如 $0.001$），所以 $(1 - \eta \lambda)$ 是一个略小于 1 的数字（比如 $0.999$）。

这意味着：在每次按照数据梯度更新参数之前，权重 $W$都会先自动打个折（乘以 0.999）

这就是Weight Decay（权重衰减）。

==Dropout==

在**训练阶段（Training）**的前向传播中，每次传入一个 Batch 的数据，Dropout 层都会生成一个随机概率（比如 $p = 0.5$），强行把一半神经元的输出变成 $0$，也就是随机丢弃

引发问题：因为现在有两倍的神经元在工作，输出的信号总和变成了 $2S$，下游的神经元突然接到比平时大了一倍的信号，预测结果全部乱套

如果在训练时只留了 p ，那给剩下的（除以 $1 - p$）。$$y_{train} = \frac{x_{train} \cdot \text{mask}}{1 - p}$$，这样一来，训练时的信号总强度就被强行拉平了

预测时关闭丢弃，按正常预测就行
